# Data Donation Study
This repository contains extraction tooling, a data donation platform, and analysis scripts for a data donation study focused on ITP data.

## Structure
- [Observations Database Extractor](/extraction): Tools to extract Safari ITP observation data from iOS and iPadOS devices.
- [Data Donation Platform](/platform): A web application for collecting and preprocessing user data donations.
- [Aggregate data](/data): Aggregated data derived from raw donations.
